# Dhikr ul Quloob

A free, offline-first Dhikr companion PWA.

## Project status
This is the **project foundation only**. The full features in the master blueprint have not been implemented yet.

## Run locally
Because this project uses JavaScript modules and a service worker, run it from a local web server rather than opening `index.html` directly.

## Publish
The intended first hosting option is GitHub Pages. Service workers require HTTPS (or localhost).

## Important
Religious content, translations, references and authenticity gradings must be verified before being added to the app.
